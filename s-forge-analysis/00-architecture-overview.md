# S-Forge 架构总览

## 基本信息

| 维度 | 内容 |
|------|------|
| **本质** | 基于 SiYuan Note 深度 fork 的个人知识管理系统 |
| **语言** | Go (kernel) + TypeScript (app) |
| **定位** | 人格管理、信息收集、情景记忆 → **"大脑"层** |
| **对应 s-code** | 执行、肌肉记忆 → **"身体"层** |

## Kernel 中的 Agent 子系统：`nerv/`

s-forge 的 agent 系统位于 `kernel/nerv/`（命名源于 EVA 的 NERV 组织），分为四个子系统：

```
nerv/
├── magi/      核心 Agent 运行时 — 多智能体决策系统
├── marduk/    人格档案系统 — IPIP-NEO-120 人格模型
├── seraph/    监控评估系统 — 评分、治疗、校准
└── dummysys/  身份锚定系统 — Avatar 身份模板
```

## 四个子系统的分工

| 子系统 | 命名来源 | 职责 | 对应 s-code 概念 |
|--------|---------|------|-----------------|
| **magi** | EVA 三贤人 | 多智能体决策、消息总线、Gateway、工具注册 | Agent 循环 |
| **marduk** | EVA MARDUK机关 | 人格档案(IPIP-NEO-120)、认知立场、种子预设 | — |
| **seraph** | 炽天使 | AT力场监控、评分、治疗、校准、对齐 | — |
| **dummysys** | EVA 模拟体 | Avatar 身份锚定、运行态管理、报告 | 工具系统 |

## 模块命名来源

所有命名均来自 **EVA (新世纪福音战士)**：

| 名称 | EVA 出处 | 含义 |
|------|---------|------|
| **NERV** | 人类补完委员会下属组织 | Agent 系统总称 |
| **MAGI** | NERV 的三台超级计算机 | Melchior/Balthazar/Casper/Trinity |
| **Melchior** | MAGI 之一 | 理性、分析、科学 |
| **Balthazar** | MAGI 之一 | 感性、人性、情感 |
| **Casper** | MAGI 之一 | 直觉、决策、果断 |
| **Trinity** | 三位一体 | 综合三贤人观点 |
| **MARDUK** | EVA 驾驶员选拔机关 | 人格选拔和匹配 |
| **SERAPH** | 炽天使 | 系统监控和计分 |
| **Dummy System** | 模拟插入栓（Dummy Plug） | Avatar 身份模拟 |
