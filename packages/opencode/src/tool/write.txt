将文件写入本地文件系统。

使用说明：
- 此工具仅用于创建新文件。如果文件已存在，此工具将报错并拒绝写入。
- 如需修改已有文件，请使用 'edit' 工具（进行部分修改）或 'write' 工具。
- 如果你持续在编辑一个文件的时候遇到困难，尝试使用删除的方式绕过是角度错误的，反思你的工具调用是否合适，或者更少见地，重构那个文件让它更易于维护。
- 绝对禁止在无法编辑一个文件的时候对它进行删除
- 始终优先编辑代码库中已有的文件。除非明确需要，否则切勿创建新文件。
- 切勿主动创建文档文件（*.md）或 README 文件。仅在用户明确请求时才创建文档文件。
- 仅在用户明确要求时使用 emoji。避免在文件中写入 emoji，除非被要求。
