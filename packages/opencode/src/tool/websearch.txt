- 使用已配置的搜索引擎搜索网络
- 内置 DuckDuckGo 搜索无需任何 API key 或配置
- 同时支持配置 API key 后的 Exa 和 Parallel 搜索服务
- 提供当前事件和训练数据之外的最新信息
- 基于查询返回最相关网站的摘要内容
- 当需要实时或近期信息且训练数据可能未包含时使用此工具

使用说明：
  - 默认使用 DuckDuckGo（免费，无需 API key）——开箱即用
  - 使用 Exa 或 Parallel 需要设置 EXA_API_KEY 或 PARALLEL_API_KEY 环境变量
  - 通过 OPENCODE_WEBSEARCH_PROVIDER 环境变量覆盖服务商（可选值："duckduckgo", "exa", "parallel"）
  - 支持实时爬取模式（Parallel 服务商）：'fallback'（默认，优先使用缓存）、'preferred'（优先实时爬取）
  - 搜索类型（当可用时）：'auto'（均衡）、'fast'（快速）、'deep'（深度）
  - DuckDuckGo 结果为每条包含标题、URL 和摘要
  - 可为 Exa/Parallel 配置上下文字符数上限以优化 LLM 输出
  - 在单个 API 调用内自动完成搜索

当前年份是 {{year}}。在搜索近期信息或当前事件时，务必使用当前年份
- 示例：如果当前是 2026 年，用户问"latest AI news"，搜索"AI news 2026"，而不是"AI news 2025"

当网络搜索不可用时，指导用户配置网络搜索服务商，或直接使用 webfetch 工具获取指定 URL 的内容。
