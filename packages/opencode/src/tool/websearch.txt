使用说明：
  - 默认使用多引擎聚合模式（DuckDuckGo + Bing + Brave + 百度 + 搜狗 + Bilibili 等 100+ 引擎），无需 API key——开箱即用
  - Brave 免费版无需 API key（每月 2000 次查询）；设置 BRAVE_API_KEY 可获得更高额度
  - 使用 Exa 或 Parallel 需要设置 EXA_API_KEY 或 PARALLEL_API_KEY 环境变量
  - 通过 OPENCODE_WEBSEARCH_PROVIDER 环境变量覆盖服务商（可选值："duckduckgo", "exa", "parallel"）
  - 支持实时爬取模式（Parallel 服务商）：'fallback'（默认，优先使用缓存）、'preferred'（优先实时爬取）
  - 搜索类型（当可用时）：'auto'（均衡）、'fast'（快速）、'deep'（深度）
  - 时间范围过滤：使用 timeRange 参数按 day/week/month/year 过滤结果
  - 语言偏好：使用 lang 参数指定语言（如 "zh-CN" 获得中文结果）
  - GitHub 仓库参考：queryType="code" 时可搜索仓库代码，或直接查询 "owner/repo" 格式读取仓库目录结构
  - 仓库文件内容：使用 "owner/repo:path/to/file" 格式可直接读取文件内容作为参考上下文
  - 每条结果包含标题、域名、URL、摘要和发布日期，多引擎结果附带来源标记
  - 可为 Exa/Parallel 配置上下文字符数上限以优化 LLM 输出
  - 在单个 API 调用内自动完成搜索
  - 引擎健康状态跨调用持久化：连续失败的引擎会自动暂停并指数退避
  - 引擎级速率限制：每个引擎有独立的最小请求间隔，防止短期内高频请求触发反爬
  - User-Agent 轮换：每次 HTTP 请求使用不同的浏览器 UA，降低机器人检测风险
